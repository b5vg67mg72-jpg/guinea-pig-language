# GUINEA PIG LANGUAGE

A responsive multi-page website for the GUINEA PIG LANGUAGE umbrella brand.

## Pages

- `index.html` — umbrella homepage
- `japanese/index.html` — complete integrated Nihongo Morumotto website
- `japanese/study-room.html` — free interactive Japanese Study Room
- `japanese/kana-foundations.html` — Kana Foundations product page
- `japanese/sentence-builder.html` — Sentence Builder product page
- `japanese/travel-japanese.html` — Travel Japanese product page
- `japanese/japan-ready-bundle.html` — Japanese bundle product page

Open `index.html` in a browser or upload the full folder to any static host.

## Before publishing

The site deliberately avoids invented staff names, customer counts, credentials, ratings, and testimonials. The statements that materials are created and checked by native speakers in Japan, Spain, and China should be published only if the actual production process supports them. Add named contributors or a documented editorial policy when available for even stronger trust.
